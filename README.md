# Agent Skills

Reusable Claude Code skills by [@luoarch](https://github.com/luoarch).

## Skills

### bug-intake

Transform non-technical CS bug reports into strong, actionable GitHub issues. Normalizes vague reports, checks for duplicates, and opens well-structured issues with the `[scope] bug: description` pattern.

#### Install

```bash
npx skills add https://github.com/luoarch/agent-skills --skill bug-intake
```
